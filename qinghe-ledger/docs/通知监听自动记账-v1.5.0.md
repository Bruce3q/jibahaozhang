# v1.5.0 改造说明：移除磁贴/截图 OCR，改为通知监听自动记账

> 版本：v1.5.0（versionCode 15）｜日期：2026-10-24｜包名：`com.qinghe.ledger`｜数据键：`qinghe.ledger.v1`（未改动）

---

## 1. 本次改造说明（方案替换原因、能力边界）

### 1.1 为什么换掉磁贴 + 截图 OCR

v1.3.x / v1.4.x 的自动记账链路是「状态栏磁贴 → 截图 → 本地 Tesseract OCR → 悬浮确认卡」，实测暴露了四个无法根治的问题：

1. **流程反人类**：用户必须先在支付页自己截屏，再下拉状态栏点磁贴；磁贴触发时还会跳回 App，需要「再点一次」。
2. **无障碍不可控**：`AccessibilityService#takeScreenshot()` 是 Android 唯一公开的系统截图入口。要用它就必须申请无障碍，而小米 HyperOS 会定期清理无障碍授权，普通应用无法静默重开；用户也明确不接受无障碍方案。
3. **悬浮窗权限被强制前置**：磁贴链路把「允许悬浮窗」当成硬前置，权限检测在 TileService / 透明 Activity 两种 Context 下结果不一致，出现「明明已授权仍一直提示」的死循环。
4. **OCR 链路脆弱**：整屏截图 + 中文模型体积极大（APK 约 28 MB），识别耗时与准确率受字号、分辨率、页面改版影响，多次出现「识别超时 / 识别失败」。

### 1.2 新方案：NotificationListenerService

微信在支付成功后会发一条系统通知（标题「微信支付」，正文含「支付成功」与金额）。新方案直接监听这条通知：

```
微信支付通知 → WeChatNotificationListenerService
             → WeChatNotifyParser（本机正则：金额 / 商户 / 时间 / 收支方向 / 分类）
             → 10 分钟去重（通知 ID + 金额 + 商户摘要）
             → 悬浮窗可用 ? 悬浮确认卡 : 普通通知（点开进 App 确认页）
             → 用户点「确认入账」→ Store.addTransactions()（复用原有记账逻辑）
```

### 1.3 能力边界（必须知道）

| 项目 | 说明 |
| --- | --- |
| 系统能力 | 使用 Android 官方 `NotificationListenerService`，只需「通知使用权」 |
| 读取范围 | 仅 `com.tencent.mm` 的**通知文本**，不读屏幕、不截图、不录屏、不注入 |
| 网络 | 解析全在本机，不联网、不上传；解析失败静默跳过 |
| 是否自动入账 | **不会**。识别后必须点「确认入账」才写入，忽略不产生任何账单 |
| 悬浮窗 | **可选**。未授权时降级为一条普通通知，点开进 App 内确认页，不再拦截流程 |
| 依赖前提 | 微信必须弹出系统通知（微信内关闭通知、或支付时处于免打扰可能收不到） |
| 后台存活 | 通知监听由系统托管，App 被划掉一般仍可用；小米 / HyperOS 建议允许「自启动」+ 电池无限制 |
| 数据兼容 | `qinghe.ledger.v1` 结构与旧版完全一致，覆盖安装不掉账单 |

### 4.3 新增 `NotifyStore.java`

```java
package com.qinghe.ledger;

import android.content.Context;
import android.content.SharedPreferences;
import android.provider.Settings;

import org.json.JSONArray;
import org.json.JSONObject;

/**
 * 通知自动记账的开关、去重与待确认缓存。
 *
 * 悬浮窗权限只用于决定「弹悬浮卡还是发通知」，不阻塞识别流程；
 * 去重键为「通知 ID + 金额 + 商户摘要」，10 分钟内同一条交易只处理一次。
 */
public final class NotifyStore {

    public static final String PREFS = "qinghe_notify";
    private static final String ENABLED = "enabled";
    private static final String PENDING = "pending";
    private static final String PENDING_AUTO = "pending_auto";
    private static final String DEDUP = "dedup";
    private static final String LAST_CONNECT = "last_connect";
    private static final long DEDUP_WINDOW_MS = 10 * 60 * 1000L;
    private static final int DEDUP_MAX = 30;

    private NotifyStore() { }

    public static SharedPreferences prefs(Context context) {
        return context.getSharedPreferences(PREFS, Context.MODE_PRIVATE);
    }

    /** 默认关闭，用户手动开启后才处理通知。 */
    public static boolean isEnabled(Context context) {
        return prefs(context).getBoolean(ENABLED, false);
    }

    public static void setEnabled(Context context, boolean enabled) {
        prefs(context).edit().putBoolean(ENABLED, enabled).apply();
    }

    public static boolean canOverlay(Context context) {
        try {
            return Settings.canDrawOverlays(context);
        } catch (Throwable e) {
            return false;
        }
    }

    public static void markConnected(Context context) {
        prefs(context).edit().putLong(LAST_CONNECT, System.currentTimeMillis()).apply();
    }

    public static long lastConnected(Context context) {
        return prefs(context).getLong(LAST_CONNECT, 0L);
    }

    /**
     * 去重：同一条交易（通知 ID + 金额 + 商户摘要）在 10 分钟内只触发一次，
     * 避免微信对同一条通知多次提醒导致重复记账。
     */
    public static synchronized boolean isDuplicate(Context context, String key) {
        SharedPreferences p = prefs(context);
        long now = System.currentTimeMillis();
        JSONArray kept = new JSONArray();
        boolean dup = false;
        try {
            JSONArray old = new JSONArray(p.getString(DEDUP, "[]"));
            for (int i = 0; i < old.length(); i++) {
                JSONObject item = old.optJSONObject(i);
                if (item == null) continue;
                long at = item.optLong("at", 0L);
                if (now - at > DEDUP_WINDOW_MS) continue;   // 过期记录顺带清掉
                if (key.equals(item.optString("sig", ""))) dup = true;
                kept.put(item);
            }
            if (!dup) {
                JSONObject item = new JSONObject();
                item.put("sig", key);
                item.put("at", now);
                kept.put(item);
            }
        } catch (Throwable ignored) {
            // 去重记录损坏时按“不重复”处理，宁可多弹一次也不要漏账
        }
        JSONArray out = new JSONArray();
        int start = Math.max(0, kept.length() - DEDUP_MAX);
        for (int i = start; i < kept.length(); i++) out.put(kept.opt(i));
        p.edit().putString(DEDUP, out.toString()).apply();
        return dup;
    }

    public static void setPending(Context context, String json, boolean autoCommit) {
        prefs(context).edit().putString(PENDING, json).putBoolean(PENDING_AUTO, autoCommit).apply();
    }

    public static String getPending(Context context) {
        return prefs(context).getString(PENDING, "");
    }

    public static boolean isPendingAuto(Context context) {
        return prefs(context).getBoolean(PENDING_AUTO, false);
    }

    public static void clearPending(Context context) {
        prefs(context).edit().remove(PENDING).remove(PENDING_AUTO).apply();
    }
}
```

### 4.4 新增 `WeChatNotifyParser.java`

```java
package com.qinghe.ledger;

import android.text.TextUtils;

import org.json.JSONObject;

import java.text.Normalizer;
import java.text.SimpleDateFormat;
import java.util.Date;
import java.util.Locale;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * 微信通知文本解析：金额、商户/对方、交易时间、收支方向与分类。
 *
 * 纯本地正则，不联网、不上传；解析失败返回 null，由调用方静默跳过。
 */
public final class WeChatNotifyParser {

    /** 金额：¥12.30 / 12.30 元 / 金额：12.30，允许千分位逗号。 */
    private static final Pattern AMOUNT = Pattern.compile(
            "(?:¥|￥|RMB)[ ]*([0-9][0-9,]*(?:[.][0-9]{1,2})?)"
            + "|([0-9][0-9,]*(?:[.][0-9]{1,2})?)[ ]*元"
            + "|(?:金额|支付金额|付款金额|收款金额|转账金额|到账金额)[:：]?[ ]*([0-9][0-9,]*(?:[.][0-9]{1,2})?)");

    private static final Pattern EXPENSE = Pattern.compile(
            "支付成功|已支付|付款成功|已付款|转账成功|已转账|转账已到账|扣款|消费成功|扫码支付|付款");

    private static final Pattern INCOME = Pattern.compile(
            "收款到账|收款成功|已收款|收到转账|转账到账|红包到账|收到红包");

    private static final Pattern MERCHANT = Pattern.compile(
            "(?:收款方|商户名称|商户|付款给|转账给|转账对象|对方|来自|向)[:：]?[ ]*([^\\n，,。;；]{2,24})");

    private WeChatNotifyParser() { }

    public static JSONObject parse(String rawText, long postTime) {
        if (TextUtils.isEmpty(rawText)) return null;
        String text = Normalizer.normalize(rawText, Normalizer.Form.NFKC)
                .replace('\u00A0', ' ')
                .replaceAll("[ \\t]+", " ")
                .trim();

        boolean income = INCOME.matcher(text).find() && !EXPENSE.matcher(text).find();
        if (!income && !EXPENSE.matcher(text).find()) return null;

        double amount = 0d;
        Matcher m = AMOUNT.matcher(text);
        while (m.find()) {
            String value = m.group(1) != null ? m.group(1) : (m.group(2) != null ? m.group(2) : m.group(3));
            if (value == null) continue;
            try {
                double v = Double.parseDouble(value.replace(",", ""));
                if (v > 0d) { amount = v; break; }
            } catch (NumberFormatException ignored) { }
        }
        if (amount <= 0d) return null;

        String merchant = findMerchant(text);
        if (merchant.isEmpty()) merchant = income ? "微信收款" : "微信支付";

        JSONObject out = new JSONObject();
        try {
            Date date = new Date(postTime > 0 ? postTime : System.currentTimeMillis());
            out.put("amount", Math.round(amount * 100d) / 100d);
            out.put("merchant", merchant);
            out.put("type", income ? "income" : "expense");
            out.put("category", income ? "income" : guessCategory(merchant));
            out.put("date", new SimpleDateFormat("yyyy-MM-dd", Locale.CHINA).format(date));
            out.put("time", new SimpleDateFormat("HH:mm", Locale.CHINA).format(date));
            out.put("source", "wechat_notify");
        } catch (Throwable ignored) { }
        return out;
    }

    private static String findMerchant(String text) {
        Matcher m = MERCHANT.matcher(text);
        if (m.find()) {
            String value = clean(m.group(1));
            if (!value.isEmpty()) return value;
        }
        // 微信常见排版：金额所在行的下一行是商户/对方
        String[] lines = text.split("\\n");
        int amountLine = -1;
        for (int i = 0; i < lines.length; i++) {
            if (AMOUNT.matcher(lines[i]).find()) { amountLine = i; break; }
        }
        if (amountLine >= 0) {
            for (int i = amountLine + 1; i < Math.min(lines.length, amountLine + 4); i++) {
                String value = clean(lines[i]);
                if (!value.isEmpty()) return value;
            }
            if (amountLine - 1 >= 0) {
                String value = clean(lines[amountLine - 1]);
                if (!value.isEmpty()) return value;
            }
        }
        return "";
    }

    private static String clean(String value) {
        String s = value == null ? "" : value.trim();
        s = s.replaceAll("^[·•\\-—\\s]+", "").replaceAll("[·•\\-—\\s]+$", "");
        if (s.isEmpty() || s.length() > 24) return "";
        if (s.matches(".*(支付成功|已支付|付款成功|收款到账|微信支付|微信转账|账单|详情|通知|凭证).*")) return "";
        if (s.matches("[0-9.,¥￥元 ]+")) return "";
        return s;
    }

    private static String guessCategory(String merchant) {
        String s = merchant == null ? "" : merchant;
        if (s.matches(".*(早餐|包子|豆浆|油条|粥).*")) return "breakfast";
        if (s.matches(".*(午餐|午饭|快餐|盖饭|面馆|小吃|米线|麻辣烫|饺子|沙县).*")) return "lunch";
        if (s.matches(".*(晚餐|晚饭|烧烤|火锅).*")) return "dinner";
        if (s.matches(".*(地铁|公交|打车|滴滴|高铁|火车|加油).*")) return "transport";
        if (s.matches(".*(超市|便利店|商场|淘宝|京东|拼多多|水果).*")) return "shopping";
        if (s.matches(".*(电影|游戏|KTV|咖啡|奶茶).*")) return "entertainment";
        if (s.matches(".*(水费|电费|燃气|物业|房租).*")) return "housing";
        if (s.matches(".*(洗澡|浴资|洗浴).*")) return "bath";
        if (s.matches(".*(饮水|矿泉水|纯净水).*")) return "water";
        return "other";
    }
}
```

/**
 * 通知监听自动记账。
 *
 * - 只处理包名 com.tencent.mm 的通知；
 * - 命中「微信支付 / 收款」类通知后，用 WeChatNotifyParser 在本机解析金额、商户、时间；
 * - 悬浮窗可用 → 直接弹悬浮确认卡；不可用 → 发一条普通通知，点开进 App 确认；
 * - 不申请无障碍、不截图、不录屏、不联网。
 */
public class WeChatNotificationListenerService extends NotificationListenerService {

    private static final String TAG = "QHNotify";
    private static final String WECHAT_PKG = "com.tencent.mm";
    private static final String CHANNEL_CONFIRM = "qinghe_notify_confirm";
    private static final Pattern TITLE_OK = Pattern.compile(
            "微信支付|微信收款|微信转账|支付助手|收款助手|转账助手|微信支付凭证");
    private static final Pattern STRONG = Pattern.compile(
            "支付成功|已支付|付款成功|收款到账|收款成功|已收款|转账成功|已转账|收到转账");

    private final Handler main = new Handler(Looper.getMainLooper());

    @Override
    public void onListenerConnected() {
        super.onListenerConnected();
        NotifyStore.markConnected(this);
        Log.i(TAG, "listener connected");
    }

    @Override
    public void onListenerDisconnected() {
        super.onListenerDisconnected();
        Log.w(TAG, "listener disconnected");
    }

    @Override
    public void onNotificationPosted(StatusBarNotification sbn) {
        try {
            handle(sbn);
        } catch (Throwable e) {
            // 静默容错：解析失败、字段缺失都不弹技术错误
            Log.e(TAG, "onNotificationPosted failed", e);
        }
    }

    private void handle(StatusBarNotification sbn) {
        if (sbn == null || sbn.getNotification() == null) return;
        if (!WECHAT_PKG.equals(sbn.getPackageName())) return;
        if (!NotifyStore.isEnabled(this)) return;
        Bundle extras = sbn.getNotification().extras;
        if (extras == null) return;
        String title = text(extras, Notification.EXTRA_TITLE);
        String content = text(extras, Notification.EXTRA_TEXT);
        String big = text(extras, Notification.EXTRA_BIG_TEXT);
        String sub = text(extras, Notification.EXTRA_SUB_TEXT);
        String full = (title + "\n" + content + "\n" + big + "\n" + sub).trim();
        Log.i(TAG, "raw title=" + title + " | text=" + content + " | big=" + big + " | sub=" + sub);

        if (!TITLE_OK.matcher(title).find() && !STRONG.matcher(full).find()) {
            Log.i(TAG, "skip: not a payment notification");
            return;
        }
        JSONObject data = WeChatNotifyParser.parse(full, sbn.getPostTime());
        if (data == null) {
            Log.i(TAG, "skip: no amount/keyword matched");
            return;
        }
        String key = sbn.getId() + "|" + data.optString("amount") + "|" + summary(data.optString("merchant"));
        if (NotifyStore.isDuplicate(this, key)) {
            Log.i(TAG, "skip: duplicate within 10min " + key);
            return;
        }
        try { data.put("nid", sbn.getId()); } catch (Throwable ignored) { }
        Log.i(TAG, "matched " + data);
        deliver(data);
    }

    private void deliver(final JSONObject data) {
        final Context app = getApplicationContext();
        if (NotifyStore.canOverlay(app)) {
            main.post(new Runnable() {
                @Override public void run() {
                    boolean shown = false;
                    try {
                        RecognitionOverlay overlay = new RecognitionOverlay(
                                WeChatNotificationListenerService.this, data,
                                new RecognitionOverlay.Callback() {
                                    @Override public void onConfirm(JSONObject result) {
                                        NotifyStore.setPending(app, result.toString(), true);
                                        openApp(app, result.toString(), true);
                                    }
                                    @Override public void onCancel() { }
                                });
                        shown = overlay.show();
                    } catch (Throwable e) {
                        Log.w(TAG, "overlay failed, fallback to notification", e);
                    }
                    if (!shown) postConfirmNotification(app, data);
                }
            });
        } else {
            postConfirmNotification(app, data);
        }
    }

    /** 无悬浮窗权限时的降级：先存 pending，再发一条可点击的通知。 */
    private void postConfirmNotification(Context context, JSONObject data) {
        try {
            NotifyStore.setPending(context, data.toString(), false);
            NotificationManager nm = (NotificationManager) context.getSystemService(Context.NOTIFICATION_SERVICE);
            if (nm == null) return;
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
                NotificationChannel channel = new NotificationChannel(CHANNEL_CONFIRM, "待确认账单",
                        NotificationManager.IMPORTANCE_HIGH);
                channel.setDescription("微信支付识别结果，点开确认后才入账");
                nm.createNotificationChannel(channel);
            }
            boolean income = "income".equals(data.optString("type"));
            String merchant = data.optString("merchant");
            String body = merchant + " · 点开确认后入账";
            Intent open = new Intent(context, MainActivity.class);
            open.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK
                    | Intent.FLAG_ACTIVITY_SINGLE_TOP | Intent.FLAG_ACTIVITY_CLEAR_TOP);
            open.putExtra("notify", data.toString());
            int flag = Build.VERSION.SDK_INT >= Build.VERSION_CODES.M
                    ? PendingIntent.FLAG_UPDATE_CURRENT | PendingIntent.FLAG_IMMUTABLE
                    : PendingIntent.FLAG_UPDATE_CURRENT;
            int requestCode = (int) (System.currentTimeMillis() % 100000);
            PendingIntent pi = PendingIntent.getActivity(context, requestCode, open, flag);
            Notification.Builder builder = Build.VERSION.SDK_INT >= Build.VERSION_CODES.O
                    ? new Notification.Builder(context, CHANNEL_CONFIRM)
                    : new Notification.Builder(context);
            builder.setSmallIcon(android.R.drawable.ic_popup_reminder)
                    .setContentTitle((income ? "识别到一笔微信收款 " : "识别到一笔微信支付 ") + "¥" + data.optString("amount"))
                    .setContentText(body)
                    .setStyle(new Notification.BigTextStyle().bigText(body))
                    .setAutoCancel(true)
                    .setContentIntent(pi);
            nm.notify(requestCode, builder.build());
            Log.i(TAG, "fallback notification posted");
        } catch (Throwable e) {
            Log.e(TAG, "postConfirmNotification failed", e);
        }
    }

    private void openApp(Context context, String json, boolean autoCommit) {
        try {
            Intent open = new Intent(context, MainActivity.class);
            open.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK
                    | Intent.FLAG_ACTIVITY_SINGLE_TOP | Intent.FLAG_ACTIVITY_CLEAR_TOP);
            open.putExtra("notify", json);
            open.putExtra("auto_commit", autoCommit);
            context.startActivity(open);
        } catch (Throwable e) {
            Log.w(TAG, "openApp failed", e);
        }
    }

    /** 通知使用权是否已授权（系统设置 → 通知使用权）。 */
    public static boolean isAccessGranted(Context context) {
        try {
            String flat = Settings.Secure.getString(context.getContentResolver(),
                    "enabled_notification_listeners");
            if (flat == null || flat.isEmpty()) return false;
            String pkg = context.getPackageName();
            String name = WeChatNotificationListenerService.class.getName();
            return flat.contains(pkg + "/" + name)
                    || flat.contains(new ComponentName(context, WeChatNotificationListenerService.class).flattenToString());
        } catch (Throwable e) {
            return false;
        }
    }

    /** 主动请求系统重新绑定监听服务（Android 7.0+）。 */
    public static void ensureRebind(Context context) {
        try {
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.N) {
                requestRebind(new ComponentName(context, WeChatNotificationListenerService.class));
                Log.i(TAG, "requestRebind sent");
            }
        } catch (Throwable e) {
            Log.w(TAG, "requestRebind failed", e);
        }
    }

    /** 开关已打开且已授权时，在 App 启动/回到前台时尝试重新绑定。 */
    public static void ensureRebindIfNeeded(Context context) {
        try {
            if (!NotifyStore.isEnabled(context)) return;
            if (!isAccessGranted(context)) return;
            ensureRebind(context);
        } catch (Throwable e) {
            Log.w(TAG, "ensureRebindIfNeeded failed", e);
        }
    }

    private static String text(Bundle extras, String key) {
        CharSequence value = extras.getCharSequence(key);
        return value == null ? "" : value.toString();
    }

    private static String summary(String merchant) {
        String s = merchant == null ? "" : merchant;
        return s.length() > 12 ? s.substring(0, 12) : s;
    }
}

## 5. 设置页引导文案（给用户看）

### 5.1 设置入口

> **通知自动记账**
> 已关闭 · 打开后才会读取微信通知

### 5.2 弹窗正文

> 开启后，微信支付或收款通知到达时，App 在本机解析金额与商户（不联网、不上传），弹出确认卡，确认后才入账。不使用无障碍、不截图、不录屏。

### 5.3 三步引导

1. **开启「通知使用权」** — 系统设置 → 通知使用权 → 允许辣脚记账读取微信通知
2. **允许悬浮窗（可选）** — 不开启也能用：改为发一条通知，点开再确认
3. **关闭电池限制** — 小米 / HyperOS 建议同时允许「自启动」，避免监听被系统清理

> 识别结果只在本机处理，直接忽略也不会产生账单。
> 未授权「通知使用权」时，App 收不到微信通知，不会自动识别。

### 5.4 微信支付后的确认卡

> **识别到一笔微信支付**
> **¥4.50**
> 香香水果店　2026-10-24 12:31
> 分类：购物 ▾　备注：香香水果店
> [忽略]　[确认入账]

### 5.5 无悬浮窗权限时的降级通知

> **识别到一笔微信支付 ¥4.50**
> 香香水果店 · 点开确认后入账
