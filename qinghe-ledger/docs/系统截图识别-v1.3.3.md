# 系统原生截图识别 · v1.3.3

> 目标：绕开小米 HyperOS「屏幕共享防护」对 MediaProjection 的强制模糊，让微信支付成功页/收款页能被清晰 OCR。
> 版本：versionCode 9 / versionName 1.3.3

## 1. 根因

1. **小米「屏幕共享防护」不是普通 FLAG_SECURE，而是系统级风控**  
   它会在检测到 MediaProjection 投屏时，把包含支付内容的窗口强制做模糊处理，并在状态栏显示「屏幕共享防护中」。这个模糊由系统图形层完成，App 拿到的已经是模糊图，无法通过代码还原。

2. **Android 没有公开的“触发系统截图”Intent**  
   `Intent.ACTION_SCREENSHOT` 之类并不存在公开可调用的动作；第三方 App 不能直接命令 SystemUI 截屏。真正可用的系统级入口是：
   - `AccessibilityService#takeScreenshot()`（Android 11+，直接返回 Bitmap，不写相册、不经过 MediaProjection）；
   - `AccessibilityService#performGlobalAction(GLOBAL_ACTION_TAKE_SCREENSHOT)`（Android 9+，等同按电源键+音量下，写系统相册）。

3. **为什么旧方案会 OCR 超时**  
   MediaProjection 得到的是被系统模糊的整屏图，模糊文字在 Tesseract 中几乎无法形成有效字符，识别耗时长且结果为空，最终触发 25/90 秒超时。

4. **微信页面布局**  
   微信收款/支付成功页是「支付成功 / 商户 / ¥金额」纵向排列，旧代码优先在金额后找商户，即使有清晰图也可能拿不到商户。

## 2. 新增/修改文件

| 文件 | 作用 |

### 3.2 原生截图（ScreenshotAccessibilityService）

```java
@Override
protected void onServiceConnected() {
    super.onServiceConnected();
    ref = new WeakReference<ScreenshotAccessibilityService>(this);
    worker.execute(new Runnable() {
        @Override public void run() { OcrEngine.warmUp(getApplicationContext()); }
    });

```

```java
takeScreenshot(Display.DEFAULT_DISPLAY, getMainExecutor(), new TakeScreenshotCallback() {
    @Override public void onSuccess(ScreenshotResult result) {
        HardwareBuffer buffer = result.getHardwareBuffer();
        Bitmap wrapped = Bitmap.wrapHardwareBuffer(buffer, result.getColorSpace());
        Bitmap copy = wrapped.copy(Bitmap.Config.ARGB_8888, false);
        buffer.close();
        process(copy, started);
    }
    @Override public void onFailure(int errorCode) {
        fallbackProjection("系统截图失败（" + errorCode + "）");
    }
});
```

```java
public static void captureAfterAppExit() {
    s.main.postDelayed(new Runnable() {
        @Override public void run() { s.takeNativeShot(); }
    }, 700);          // 等授权/页面退场动画结束
}
```

## 4. 四条验证步骤

### ① 默认系统截图模式（核心）

1. 安装 v1.3.3，打开 App → 我的 → 状态栏一键记账。
2. 确认「识别模式 = 系统截图 · 推荐」。
3. 点第 1 步，到系统设置 → 无障碍，开启「辣脚记账 · 系统截图」。
4. 回到微信支付成功页/收款页（如 `待XX确认收款 / ¥2.00`），下拉状态栏点「记账识别」。
5. 预期：**不出现「屏幕共享防护」**，状态栏也没有投屏图标；约 1–3 秒弹出确认卡，金额/商户正确。

日志：

```bash
adb logcat -s QHNativeShot QHOCR QHTile
# native screenshot start
# native screenshot ok 1080x2400 cost=...
# bitmap meanGray=2xx
# ocr input 1000x... cropRatio=0.45
# matched merchant=... amount=2.00
```

### ② 旧方案防护提示

1. 我的 → 状态栏一键记账 → 识别模式切「旧方案」。
2. 回微信支付页点磁贴。
3. 预期：先看到「小米屏幕共享防护提示」，不会再直接进入 25 秒超时；可选择「仍用旧方案」继续，或取消并切回系统截图。

### ③ 框选/裁剪调试

1. 在系统截图模式下点磁贴，识别成功或失败后查看 `Pictures/辣脚记账` 里的临时图（关闭自动删图时保留）。
2. 用调试桥调整裁剪比例/宽度后重试：

```js
// 目前可调 OCR 宽度与超时；裁剪比例在 OCR_CROP_RATIO=0.45
QHRecognition.setOcrConfig(8000, 120000, 1000);
```

3. 对比 `QHOCR` 的 `raw text begin/end`，确认上半屏文字完整，未被裁掉商户或金额。

### ④ 自动删图

1. 保持「识别后自动删图」开启（默认）。
2. 识别成功后检查相册 `Pictures/辣脚记账`：不应留下本次临时图。
3. 日志应出现：

```bash
# temp screenshot uri=content://media/...
# temp screenshot deleted rows=1
```

4. 若关闭开关，再识别一次，临时图会保留，便于排查 OCR。

## 已知边界

- **必须开启无障碍服务**：这是 Android 允许第三方 App 调用系统截图的唯一公开入口；本服务只调用 `takeScreenshot`，`canRetrieveWindowContent=false`，不读取页面文字。
- Android 10 及以下不支持 `takeScreenshot()`，会自动降级到 MediaProjection，仍可能触发小米模糊。
- 小米「电诈防护」可能随系统更新改变入口；App 内提示的是 HyperOS 常见路径。
- 系统截图不经过 MediaProjection，但仍受系统 `FLAG_SECURE` 限制；若支付页本身禁止截屏，会得到黑屏。
- 未做真机微信支付实测，以上为代码与构建级验证。
