最值得用的 10 个变化

按使用频率排序，每条都能在 1 分钟内学会。

01

支付页三个快捷入口

悬浮球、通知栏「记一笔」、状态栏磁贴——在付款成功页点一下就能记，不用切回 App。悬浮球可拖动吸边，不用时自动收起。

02

三餐可记「这餐没吃」

勾选后按 0 元保存，账单显示「未用餐」，不增加支出，但三餐记录是完整的。

03

分类从 9 个变 12 个

新增 洗澡、饮水、洗衣，颜色图标与原来一致；统计、预算、账单自动识别，旧账单不用处理。

04

累计结余1.6.3 增强

单月结余 = 当月预算 − 实际支出，再逐月累加。现在可以点 ‹ › 或点柱状图切换月份，查看任意一月。

05

预算校准

当月账单和实际花费对不上时，可手动填一个更真实的「已消费」；只影响预算显示，不改账单，可随时恢复自动。

06

备注搜索1.6.3 增强

输入「奶茶」「房租」就能查；新增起止日期，选好时段只统计这段时间的花费，不选就是全局搜索。

07

导入微信 / 支付宝账单

支持 CSV、XLSX，本机解析不上传；导入前可逐条勾选、改分类，重复交易自动跳过。

08

日历备注

给某一天写一句话，如「发工资」「聚餐」「出差」，翻月、备份、恢复都不会丢。

09

自定义周期账单

任选起止日期，查看这段时间的总收支、笔数和分类明细，还能直接导出 CSV。

10

周期提醒 + 系统通知

提醒支持每天 / 每周 / 每月 / 每年，Android 版本用系统通知，锁屏也能收到。

升级只要 3 步

覆盖安装即可，账单、预算、设置全部保留。

1

先备份

我的 → 数据备份 → 导出 JSON，发到文件传输助手存一份。

2

覆盖安装

打开新 APK，允许「未知来源」安装；不要先卸载。

只申请 3 个可选权限：悬浮窗（悬浮球）、通知（提醒）、忽略电池优化（后台稳定）。
不申请：无障碍、读屏、相册、通讯录、定位 —— 不读聊天、不截屏、不联网上传。
小米 / Redmi：设置里给辣脚记账开「自启动」和「电池无限制」，悬浮球与提醒会更稳。

大家最常问的 4 个问题

Q1 升级后账单会丢吗？

不会。覆盖安装保留本地数据；仍建议先导出一次 JSON 备份，多一层保险。

Q2 以前的「自动识别支付」怎么没了？

试过读屏、截图识别、通知监听三种方案，在小米等机型上常被系统关闭、权限又重。1.6 起改为三个更可靠的手动入口 + 账单导入，不读屏不截屏，更省电也更安心。

Q3 悬浮球不显示 / 磁贴找不到？

悬浮球：我的 → 快速记账 → 悬浮球，开启并允许「显示在其他应用上层」。磁贴：下拉控制中心 → 编辑 → 把「辣脚记账 · 记一笔」拖进面板。

Q4 换手机怎么迁移？

旧手机导出 JSON 备份，新手机安装后用「数据恢复」选择该文件即可，账单、预算、备注一起过去。
