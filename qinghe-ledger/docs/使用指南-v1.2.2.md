# 辣脚记账 v1.2.2 使用指南

> 适用版本：Android APK v1.2.2（versionCode 5）、网页/PWA v1.2.2  
> 数据仍然只保存在本机，无账号、无云端、无广告。

---

## 一、一分钟上手

1. 打开 App，首页只有两个大按钮：**记一笔**、**收入**。
2. 点「记一笔」→ 选早餐/午餐/晚餐/洗澡/饮水等分类 → 输金额 → 保存。
3. 点底部「日历」→ 选日期 → 下方就是当天的总收支、分类占比和账单明细。
4. 点底部「统计」→ 看月度收支、分类占比、三餐专项和累计结余。
5. 点底部「我的」→ 设置预算、提醒、通知权限、自动识别、导入和备份。

---

## 二、安装与升级

### Android（推荐）

1. 安装 `dist/辣脚记账.apk`，允许「安装未知来源应用」。
2. 新版本可以直接覆盖安装旧版本，**账单和设置会保留**。
3. 首次启动 Android 13 及以上会请求一次通知权限，建议点「允许」。
4. 如果要使用支付自动识别，再按本文第四节开启无障碍和悬浮窗。

### iPhone / 浏览器

1. 把 `dist/pwa/` 整个目录或 `dist/辣脚记账-PWA.zip` 上传到任意 HTTPS 静态托管。
2. iPhone 用 **Safari** 打开网址 → 分享 → 添加到主屏幕。
3. iPhone 不支持 APK，也没有 Android 的无障碍自动识别；可以用 CSV/XLSX 导入账单。

## 三、日常记账

### 3.1 首页「记一笔」

- 点「记一笔」先出现分类面板，共 11 类：
  早餐、午餐、晚餐、交通、购物、娱乐、日用、洗澡、饮水、住房、其他。
- 选完分类进入金额面板：
  - 可点 5 / 10 / 20 / 50 / 100 快速填金额；
  - 可加备注；
  - 保存后立即写入日历、预算和统计。
- 首页「收入」直接进入收入金额面板，默认分类为「工资/红包/报销等」。

### 3.2 三餐 0 元

- 早餐/午餐/晚餐可以记 **0 元**，用于表示「这餐没吃」。
- 0 元记录会显示「已记录 · 未用餐」，计入账单笔数，但**不计入支出总额**。
- 其他分类仍然必须大于 0 元。

### 3.3 改账、删账

- 日历选中日期 → 当日明细 → 点铅笔修改，点垃圾桶删除。
- 也可以点「+ 补记」给选中日期补一笔。

## 四、支付自动识别：什么情况下会「自动记账」

### 4.1 先给结论

**严格来说，这个版本不会静默自动入账。**  
自动发生的是：识别支付成功页 → 弹出确认卡片。  
**必须由你点「确认入账」才会写入账本。**

这样设计是为了避免把转账、退款、测试支付误记成消费。

### 4.2 会弹出确认卡的完整条件

以下条件必须**同时满足**：

| 条件 | 说明 |
| --- | --- |
| 使用 Android APK | 网页版、PWA、iPhone 都没有无障碍识别 |
| 总开关已开启 | 「我的 → 支付页面自动识别」→ 开启 |
| 识别模式为「无障碍识别」 | 屏幕 OCR 模式当前未启用 |
| 系统无障碍服务已开启 | 系统设置 → 无障碍 → 辣脚记账 |
| 当前前台是微信 / 支付宝 / 云闪付 | 只监听这三个包名，其它 App 完全不读 |
| 页面出现成功关键词 | 支付成功 / 付款成功 / 已支付 / 交易成功 / 转账成功 / 转账已到账 / 已转账 / 收款成功 / 已收款 |
| 页面能读到大于 0 的金额 | 优先「转账金额/支付金额/收款金额」等标签，其次 `¥/￥`，再其次「x 元」，最后读 `x.xx` 格式 |
| 3 次窗口内读到结果 | 进入页面后 0 / 450 / 1150 毫秒各读一次，适配支付页转场动画 |
| 8 秒内没有重复事件 | 防止同一页面反复弹卡 |
| 与上一次识别不是同一笔 | 用「商户 + 金额 + 分钟」做一次快速去重 |

满足后会显示：

- 有悬浮窗权限：在支付页底部弹出「辣脚记账 · 识别到支付」确认卡；
- 没有悬浮窗权限但 App 正在前台：在 App 内弹出确认卡；
- 没有悬浮窗权限且 App 在后台：先把结果暂存，等你下次打开 App 时再确认。

### 4.3 确认卡上可以做什么

- 查看金额、商户、时间；
- 修改分类（默认自动匹配，失败归「其他」）；
- 修改备注；
- 点「忽略」不记账；
- 点「确认入账」才真正写入。

确认后会立即同步到日历、预算剩余、统计报表和累计结余。

### 4.4 哪些情况不会触发

- 支付页面没有出现上述成功关键词；
- 页面是聊天、通讯录、账单列表、付款码页，而不是支付成功页；
- 页面金额为 0、金额读不到，或只出现「¥0.00」；
- 微信/支付宝的小程序或内嵌网页没有把文字暴露给无障碍服务（常见于部分 H5 页面）；
- 无障碍服务被系统清理、被手动关闭，或辣脚记账被「强行停止」；
- 识别总开关关闭，或模式被切到「屏幕识别」；
- 同一笔支付在 800 毫秒内重复触发，或与上一笔签名完全相同；
- 支付发生在锁屏、分屏其它应用，或当前前台不是这三个支付应用。

### 4.5 首次开启步骤

1. 打开「我的」→「支付页面自动识别」。
2. 点「开启无障碍服务」，跳到系统设置，找到「辣脚记账」并开启。
3. 返回 App，点「允许悬浮窗」，在系统设置里允许「显示在其他应用上层」。
4. 如系统有电池限制，把辣脚记账设为「不限制」，避免服务被后台清理。
5. 开启总开关，做一笔小额支付测试；开启后通知栏会出现一条低优先级的「支付识别运行中」，这是保活通知，不会打扰。

> 无障碍服务只读取当前窗口的可见文字，不点击、不注入、不截屏、不抓包，也不会上传任何内容。

### 4.6 去重规则

自动识别、手动记账、账单导入共用同一套去重指纹：

`日期 + 时间 + 收支类型 + 金额 + 分类 + 备注`

如果同一笔已经手动记过或导入过，确认入账时会提示已存在并跳过，不会重复扣预算。

### 4.7 识别不到怎么排查

按顺序检查：

1. 「我的 → 支付页面自动识别」总开关是否打开；
2. 系统无障碍里辣脚记账是否仍是开启状态（有些系统升级后会关掉）；
3. 是否给了悬浮窗权限；
4. 电池优化是否限制了这个 App；
5. 支付成功页是否真的显示了「支付成功」等字样；
6. 如果是转账：页面必须停在「转账成功 / 已转账 / 转账已到账 / 已收款」结果页，只停在聊天窗口或「确认转账」页不会触发；
7. 换一笔真实小额支付再试，避免用 0 元或测试订单。

如果仍然识别不到，可以直接手动记一笔，或从微信/支付宝导出 CSV/XLSX 后导入。

### 4.8 退出 App 后无障碍被系统关闭怎么办

v1.2.2 增加了低优先级前台服务保活，并在回到 App 时自动检测真实的无障碍状态；但部分品牌系统仍会强制关闭无障碍，需要手动做三件事：

1. 系统设置 → 应用 → 辣脚记账 → 电池 → 选「不限制 / 允许后台活动」；
2. 在系统管家里允许辣脚记账「自启动」，并在最近任务里给 App 加锁；
3. 如果通知栏的「支付识别运行中」消失，或 App 内提示「系统已关闭无障碍服务」，重新到系统无障碍设置开启一次即可。

这不是 App 能绕过的系统权限：Android 只允许用户在系统设置里开启/关闭无障碍，任何应用都无法静默重新开启。

## 五、导入微信 / 支付宝账单

入口：「我的」→「导入微信 / 支付宝账单」。

支持：

- CSV（UTF-8 / GB18030 自动识别）
- XLSX
- Excel 2003 XML（`.xls`）

不支持：

- PDF（需要 OCR 引擎，当前版本会提示改用 CSV/XLSX）

流程：

1. 选择文件，本地解析，不上传；
2. 预览列表逐行显示日期、商户、金额、分类；
3. 可勾选/取消、修改分类；
4. 重复交易会标记「已存在，将跳过」；
5. 点「确认入账」批量写入。

导入的分类匹配覆盖三餐、洗澡、饮水、交通、购物、娱乐、日用、住房等，匹配失败归「其他」。

## 六、预算、校准与累计结余

### 6.1 预算分配

预算页顶部是「本月可自由分配金额」：

```
可自由分配 = 月度总预算 − 所有分类已分配预算之和
```

- 修改总预算或任一分类预算，数字实时刷新；
- 它表示「还没分配出去的预算」，**不等于**本月消费剩余；
- 下方「本月消费剩余」才是预算减去实际消费后的钱。

### 6.2 校准本月已消费

适合月中开始用、或旧账单不完整的情况：

- 预算页 →「校准本月已消费」；
- 填入一个符合真实开销的数值；
- 只影响预算剩余和累计结余，不改任何账单明细；
- 可随时「恢复自动统计」。

### 6.3 累计结余

统计页顶部：

```
单月结余 = 当月总预算 − 当月实际支出
累计结余 = 所有历史月份结余之和
```

同时展示近 12 个月结余柱状图：绿色为结余，红色为超支。

## 七、提醒与系统通知（v1.2.1 重点修复）

### 7.1 五种提醒

- 每日消费小结
- 每日记账提醒
- 每周总结（每周一）
- 每月总结（每月 1 日）
- 每年总结（每年 1 月 1 日）

每种都可以单独设时间、单独开关。

### 7.2 Android 通知权限

- Android 13+ 首次启动会**自动请求一次**通知权限；
- 如果当时点了拒绝，之后在「我的 → 提醒」底部点「去开启」，会跳到系统通知设置；
- 授权成功后，提醒到点会通过系统通知栏发送，同时保留应用内弹窗。

### 7.3 通知什么时候能收到

- App 进程仍在运行（前台或后台）时，按设定时间检查并发送；
- 如果 App 被手动「强行停止」，或系统清理了进程，定时检查会停止；
- 重新打开 App 后，会补检查当天尚未触发的提醒。

这是没有常驻前台服务时的系统限制，App 不会为了推送常驻通知栏。

## 八、数据、备份与外观

- 所有账单保存在本机 `localStorage`，不登录、不上传。
- 备份：「我的 → 备份数据」导出 JSON；恢复：「恢复数据」选择 JSON。
- 导出：「我的 → 导出 CSV / Excel」保存到系统下载目录（Android 为「下载/辣脚记账」）。
- 主题：抹茶、海盐、琥珀、樱花、鸢尾五套低饱和配色。
- 深色模式：跟随系统 / 浅色 / 深色。
- 货币单位可自定义，最多 3 个字符。

> APK 与浏览器/PWA 的本地数据不互通；换机或换安装方式前，请先导出 JSON 备份。

## 九、常见问题

**Q：为什么支付成功了，没有自动记账？**  
A：本版本不会静默入账。先确认是否弹出了确认卡；如果没有，按 4.7 检查权限和页面文字。部分小程序页面读不到文字，属于系统无障碍限制。

**Q：为什么显示“系统通知已开启”，但还是没收到？**  
A：确认 App 进程没有被强行停止；Android 设置里辣脚记账的通知没有被关闭；电池优化没有限制它。网页/PWA 关闭后无法后台推送。

**Q：0 元早餐为什么支出没变？**  
A：0 元只表示「这餐没吃」，计入笔数，不计入支出，这是设计行为。

**Q：自动识别会不会把我的聊天内容上传？**  
A：不会。只读取三个支付应用的当前窗口文字，在本机匹配，识别服务没有网络上传逻辑，也不读取聊天列表。

**Q：导入 PDF 为什么失败？**  
A：当前版本没有本地 OCR，PDF 无法可靠解析；请从微信/支付宝导出 CSV 或 XLSX。

**Q：换手机怎么迁移？**  
A：旧手机「我的 → 备份数据」导出 JSON，新手机安装后「恢复数据」选择该 JSON。

## 十、版本要点

v1.2.2 相对 v1.2.1：

- 新增支付识别前台保活服务，降低退出 App 后无障碍被系统清理的概率；
- 回到 App 自动校验无障碍真实状态，避免开关「假开启」；
- 扩展转账成功页关键词与金额识别（转账成功 / 已转账 / 到账 / 元）；
- 「关闭电池限制」改为直接申请本应用电池白名单。

v1.2.1 相对 v1.2.0：

- 修复 Android WebView 误报「不支持系统通知」；
- 新增原生通知发送通道；
- Android 13+ 首次启动自动申请通知权限；
- 拒绝后「去开启」直达系统通知设置；
- 返回 App 自动刷新权限状态。

v1.2.0 相对 v1.1.0：

- 全局更名辣脚记账、脚掌图标；
- 0 元三餐、洗澡/饮水分类；
- 无障碍支付识别与确认卡；
- 预算校准、累计结余；
- CSV/XLSX 账单导入、自定义周期统计；
- 每周/每月/每年总结提醒。
