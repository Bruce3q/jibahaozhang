### 4.2 QuickTileService.java（新增，完整）

```java
package com.qinghe.ledger;

import android.app.PendingIntent;
import android.content.Intent;
import android.graphics.drawable.Icon;
import android.os.Build;
import android.service.quicksettings.Tile;
import android.service.quicksettings.TileService;

/** 状态栏磁贴「记一笔」：只做快捷入口，点击直接打开 App 的记账面板，不做任何识别。 */
public class QuickTileService extends TileService {

    @Override
    public void onStartListening() {
        super.onStartListening();
        updateTile();
    }

    @Override
    public void onClick() {
        super.onClick();
        Intent open = new Intent(this, MainActivity.class);
        open.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK
                | Intent.FLAG_ACTIVITY_SINGLE_TOP | Intent.FLAG_ACTIVITY_CLEAR_TOP);
        open.putExtra("quick_add", true);
        if (Build.VERSION.SDK_INT >= 34) {
            PendingIntent pi = PendingIntent.getActivity(
                    this, 0, open, PendingIntent.FLAG_UPDATE_CURRENT | PendingIntent.FLAG_IMMUTABLE);
            startActivityAndCollapse(pi);
        } else {
            startActivityAndCollapse(open);
        }
    }

    private void updateTile() {
        try {
            Tile tile = getQsTile();
            if (tile == null) return;
            tile.setIcon(Icon.createWithResource(this, R.drawable.ic_tile_ledger));
            tile.setLabel(getString(R.string.tile_label));
            if (Build.VERSION.SDK_INT >= 29) {
                tile.setState(Tile.STATE_INACTIVE);
            }
            tile.updateTile();
        } catch (Throwable ignored) { }
    }
}
```

## 5. 九项需求自测步骤

1. **磁贴**：下拉控制中心 → 编辑 → 把「记一笔」拖进快捷面板 → 点磁贴：应直接打开 App 的「记一笔」分类面板；控制中心不应出现任何识别/截图字样。
2. **删除小窗识别**：我的 → 快速记账，只有悬浮球 / 磁贴 / 通知栏 / 小组件四项；`设置 → 应用 → 辣脚记账 → 权限` 中不应有「照片和视频」；APK 内 `assets/` 无 `tessdata`。
3. **删除通知自动记账**：我的页不应出现「通知自动记账 / 微信支付通知」；系统「通知使用权」列表里不应有辣脚记账。
4. **悬浮球吸边**：打开悬浮球 → 按住小球拖到屏幕中间松手：应吸附到最近一侧，并收起为迷你图标；点迷你图标展开完整卡片，卡片不再遮挡大半个屏幕。
5. **统计顺序**：打开统计 → 向下滚动：顺序应为 分类占比 → 收支趋势 → 三餐专项统计 → 累计结余 → 备注搜索。
6. **小组件自定义**：我的 → 桌面小组件 → 自定义金额与显示项：关掉「午餐」、把早餐改成 8 → 保存 → 桌面上小组件的午餐按钮消失、早餐显示 ¥8。
7. **日历备注**：日历 → 选一天 → 添加备注「放纵日」→ 保存：日面板出现备注条，进入该日详情仍能看到；删除备注后恢复「添加」。
8. **备注搜索**：统计 → 备注搜索输入「放纵日」：显示关联账单笔数与关联总花费；换关键词结果随之变化；清空后只剩提示。
9. **补记全分类**：日历 → 补记：弹出 11 个分类 + 收入，不再直接落在「其他」。

## 6. 已知限制

- 磁贴需要用户在控制中心手动添加（系统行为，App 无法自动放入）。
- 小组件刷新依赖系统广播；部分 HyperOS 机型把 App 加入「省电限制」后刷新会延迟，打开一次 App 即恢复。
- 悬浮球长时间后台仍可能被 OEM 清理，重开 App 会自动恢复；建议 HyperOS 打开「自启动」。
- 网页版没有磁贴/小组件/悬浮球，只保留记账、备注、搜索等纯前端能力。
