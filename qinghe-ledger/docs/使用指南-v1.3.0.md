# 辣脚记账 v1.3.0 · 状态栏一键记账使用指南

> 本版把「支付自动识别」从无障碍常驻监听，改为 **状态栏快捷磁贴 + 单帧截图 + 本地 OCR**。
> 只有你主动点磁贴时才识别一次；不点，不截屏、不监听、不耗电。

---

## 1. 方案原理、适用场景、优缺点

### 原理

1. 安卓快捷设置面板（下拉状态栏）里有一个「记账识别」磁贴，和截图、录屏同类。
2. 你在微信 / 支付宝 / 云闪付的支付成功页，下拉状态栏点一下磁贴。
3. App 申请一次系统屏幕捕获（MediaProjection），只截当前一帧。
4. 图片交给内置的 Tesseract 中文 OCR，在本机识别全部文字。
5. 只有出现「支付成功 / 付款成功 / 转账成功 / 转账已到账 / 收款成功」等关键词时，
   才提取金额、商户、时间，并弹出确认卡。
6. 你点「确认入账」才写入账本；点「忽略」什么都不发生。
7. 识别结束立即释放截图和捕获资源，不后台循环、不上传云端。

### 适用场景

- 微信、支付宝、云闪付的支付成功页；
- 转账成功页（如微信「转账给 XXX」）；
- 想保留人工确认、不愿让 App 常驻监听屏幕的用户。

### 优点

- **不常驻**：不用无障碍服务，不监听通知，不会被系统当作常驻监控；
- **手动触发**：一次点击只识别一次，行为可预期；
- **本地 OCR**：图片不出手机，不依赖网络；
- **确认才入账**：不会静默扣账，分类和备注都能改；
- **规避 HyperOS 杀后台**：不依赖后台常驻，点一下才启动前台服务。

### 缺点与边界

- 必须手动下拉点磁贴，无法自动识别；
- OCR 对字体、分辨率、页面改版敏感，识别失败需重试；
- 首次使用要授权「屏幕捕获」和「悬浮窗」；
- Android 冷启动后第一次点击会再询问一次屏幕捕获；进程内 90 秒空闲后释放；
- 与网页版、PWA 的数据不互通。

### 点击链路

```
Tile 点击
  └─ RecognitionTileService.onClick
      ├─ 未开悬浮窗 → 系统悬浮窗设置
      └─ CapturePermissionActivity（透明）
          ├─ 无 Projection → createScreenCaptureIntent 授权
          └─ 有 Projection → ScreenOcrService.start()
               ├─ 前台通知（mediaProjection）
               ├─ VirtualDisplay + ImageReader 截一帧（3s 超时）
               ├─ Tesseract OCR（25s 超时）
               ├─ PayPageParser 匹配成功页
               ├─ 2 分钟同商户+金额去重
               ├─ RecognitionOverlay 悬浮确认卡
               │    ├─ 忽略 → 释放
               │    └─ 确认 → pending + 拉起 MainActivity
               │         └─ QHApp.commitRecognition() → 账本
               └─ 释放 VirtualDisplay / ImageReader / Bitmap
```

## 6. 4 条自测步骤

1. **磁贴出现**：安装 APK → 下拉控制中心 → 编辑 → 添加「记账识别」→ 磁贴显示为绿色可用状态。
2. **权限链路**：点磁贴 → 首次跳悬浮窗设置，授权后返回再点 → 出现系统「开始录制/截屏」授权 →
   允许后应看到前台通知「辣脚记账 · 正在识别」，随后通知消失。
3. **正常识别**：在微信给朋友转 0.01 元或买一瓶水，停留在「支付成功 / 转账成功」页 →
   下拉点磁贴 → 悬浮卡显示金额与商户 → 改分类/备注 → 「确认入账」→ App 首页/日历出现该笔。
4. **容错与去重**：在聊天页点磁贴 → 提示「未识别到支付信息」且不崩溃；连续两次识别同一笔 →
   第二次提示「刚刚已识别过同一笔」；点「忽略」不产生账单；重启手机后首次点磁贴会重新请求屏幕捕获。

调试：`adb logcat -s QHTile` 可看到每次点击、权限状态、OCR 原文（截断 4000 字）、匹配结果。

## 7. 小米 HyperOS 配套设置提示

建议在系统设置中完成：

1. **悬浮窗**：设置 → 应用设置 → 应用管理 → 辣脚记账 → 权限管理 → 悬浮窗 → 允许。
   部分 HyperOS 还需开启「后台弹出界面」。
2. **电池策略**：设置 → 应用设置 → 辣脚记账 → 省电策略 → **无限制**；
   或在最近任务里长按 App → 锁定。
3. **自启动**：设置 → 应用设置 → 授权管理 → 自启动 → 允许辣脚记账。
4. **通知**：设置 → 通知与控制中心 → 辣脚记账 → 允许通知；否则前台识别通知可能不显示。
5. **屏幕捕获**：HyperOS 可能在每次冷启动后重新询问「开始录制或投放」，这是系统行为，
   App 无法静默绕过；点「立即开始」即可。

> 如果点磁贴后只看到通知、没有悬浮卡：优先检查「悬浮窗」和「后台弹出界面」；
> 如果识别总是超时：把省电策略改为无限制，并在点磁贴后停留 1–2 秒再切走。

## 隐私说明

- 截图只存在于内存，OCR 完成后立即回收；不写入相册、不上传服务器。
- 不读取聊天、通讯录、通知；只有你点磁贴时截取当前一屏。
- 账本仍然只存在本机 `localStorage`；换机请用「备份数据」导出 JSON。
