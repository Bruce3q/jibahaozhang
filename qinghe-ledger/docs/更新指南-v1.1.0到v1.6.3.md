## 二、记账更快了

### 1. 支付页三个快捷入口（1.6.0 起）

在微信/支付宝付款成功页，不用切回 App：

- **悬浮球**：打开后屏幕边缘有一个小圆球，点一下弹出记账小窗，11 个分类 + 数字键盘，输金额保存即可；小球可拖动，松手自动吸边，不用时会缩成半圆，不挡内容。
- **通知栏常驻「记一笔」**：下拉通知栏点一下，直接打开记账面板。
- **状态栏磁贴「记一笔」**：把磁贴拖进控制中心，下拉点一下直接打开记账面板。

三个入口都只做「打开记账面板」，不读取屏幕、不截屏、不监听聊天，权限只用「显示在其他应用上层」和「通知」，都可以随时关掉。

### 2. 三餐可以记「这餐没吃」

记账面板里勾选「这餐没吃 / 记 0 元」，保存后账单显示为「未用餐」，金额 0，不计入支出。适合出差、断食、忘吃的情况——三餐记录完整，但钱不会多算。

### 3. 分类从 9 个变成 12 个

新增 **洗澡、饮水、洗衣** 三个日常高频分类，颜色和图标与原有一致：

- 洗澡：浴资、洗浴中心
- 饮水：桶装水、矿泉水
- 洗衣：洗衣店、干洗、自助洗衣

新分类会自动出现在「记一笔」、账单明细、分类统计和分类预算里，旧账单不需要任何处理。

### 4. 补记走完整分类面板

以前补记默认落在「其他」，现在点补记会打开完整分类面板，选好分类再输金额，和正常记账一致。

## 三、账更好查了

### 5. 日历备注

在日历里点某一天，可以写一句备注，例如「发工资」「朋友聚餐」「出差」。备注会跟着这一天保存，翻月、备份、恢复都不会丢。

### 6. 备注搜索（1.6.3 增强）

统计页新增「备注搜索」：

- 输入关键词，例如「奶茶」「房租」「药」，列出所有备注包含该词的账单，并给出**关联总花费**；
- **1.6.3 新增起止日期**：选好「从 … 到 …」后，只统计这个区间内匹配的账单；不选日期就是全局搜索；
- 结果里直接显示「统计时段」，一眼看出这次统计覆盖哪几天；
- 点「清除」回到全局搜索，关键词保留。

### 7. 自定义周期账单

日历顶部新增「自定义周期」：任选起止日期，查看这段时间的总支出、总收入、笔数和分类明细，并可导出 CSV。适合「这个月 15 号到月底花了多少」「出差一周花了多少」这类问题。

## 四、钱更清楚了

### 8. 累计结余，可按月查看

统计页底部新增「累计结余」：

- 单月结余 = 当月总预算 − 当月实际支出；
- 累计结余 = 从有账单的第一个月累加到当前月；
- **1.6.3 新增月份切换**：点 ‹ › 或直接点柱状图，就能查看任意一个月的结余，不再只能看当前月。

> 注意：累计结余看的是「预算与支出的差额累加」，和首页的「本月消费剩余」不是同一个数。前者是长期账，后者是当月余额。

### 9. 预算校准

有时账单和实际花费对不上（比如有一部分用现金、或某笔忘了记），可以在预算页点「校准本月已消费」，手动填一个更接近真实的数字：

- 只影响预算剩余和累计结余的显示，**不会修改任何一笔账单**；
- 随时可以点「恢复自动统计」回到按账单计算。

### 10. 分类预算覆盖新分类

除月度总预算外，三餐、洗澡、饮水、洗衣等 12 个分类都可以单独设预算；预算页会实时显示「本月可自由分配 = 总预算 − 各分类预算之和」，分配超了会提示。

## 五、数据、提醒与外观

### 11. 微信 / 支付宝账单导入

我的 → 导入微信 / 支付宝账单：

- 支持 CSV、XLSX（微信、支付宝导出的账单文件）；
- 全程在本机解析，不上传；
- 导入前有预览：逐条勾选、可改分类、自动标记重复项；
- 确认后一次性入账，重复交易会自动跳过。

### 12. 周期提醒 + 系统通知

提醒支持每天 / 每周 / 每月 / 每年四种周期，可分别设时间。Android 版使用系统通知通道，锁屏也能收到；首次启动会请求通知权限，拒绝后可以在「我的 → 提醒」里点「去开启」。

### 13. 导出与备份

- 导出 Excel / CSV：按当前筛选范围导出，可直接用表格软件打开；
- JSON 备份：包含账单、预算、校准、日历备注、设置，换手机时用它恢复；
- 恢复前会校验文件，损坏的文件不会覆盖现有数据。

### 14. 外观

主题色、深色模式（跟随系统）、货币单位自定义都保留；深色模式下所有新页面（悬浮球小窗、磁贴入口、统计卡）同样适配。

## 六、升级前必读

### 升级步骤（3 步）

1. **先备份**：打开旧版 → 我的 → 数据备份 → 导出 JSON，存到微信文件传输助手或网盘。
2. **覆盖安装**：下载 `辣脚记账-1.6.3.apk` → 点击安装 → 如提示「未知来源」，允许本次安装 → 直接覆盖，不要先卸载。
3. **打开检查**：确认账单一览、预算、提醒都还在；需要悬浮球/磁贴的，按下面「权限」开启。

> 覆盖安装会保留数据；**卸载重装会清空本地数据**，务必先备份。

### 需要哪些权限（都可选）

| 权限 | 用在哪 | 不开会怎样 |
| --- | --- | --- |
| 显示在其他应用上层 | 悬浮球、悬浮确认卡 | 悬浮球不可用，其他功能正常 |
| 通知 | 记账提醒、周期提醒 | 收不到提醒，其他功能正常 |
| 忽略电池优化 | 让提醒/悬浮球在后台稳定 | 系统可能清理后台，提醒延迟 |

**不申请**：无障碍、读取屏幕、读取相册、通讯录、定位。App 不读取你的聊天内容，也不截屏。

### 小米 / Redmi（HyperOS）用户

如果悬浮球或提醒偶尔失效，按下面三处设置一次即可：

1. 设置 → 应用设置 → 辣脚记账 → **自启动**：允许；
2. 同上 → **省电策略**：无限制；
3. 通知管理 → 允许通知、允许锁屏通知。

### iPhone 用户

iPhone 不能安装 APK。继续用网页版：Safari 打开地址 → 分享 → 添加到主屏幕，使用方式与 App 一致；数据保存在 Safari 本地，换手机前请在 App 内导出备份。

## 八、常见问题

**Q1：升级后账单会丢吗？**
不会。覆盖安装保留本地数据；仍建议升级前导出一次 JSON 备份，多一层保险。

**Q2：以前的「自动识别支付」怎么没了？**
我们试过无障碍读屏、截图 OCR、微信通知监听三种方案，但在小米/HyperOS 等机型上经常被系统关闭，还要一堆权限，反而不稳。1.6.x 起改成三个更可靠的手动入口（悬浮球 / 通知栏 / 磁贴）+ 账单导入，不读屏、不截屏、不监听聊天，更省电也更安心。

**Q3：悬浮球找不到了 / 不显示？**
我的 → 快速记账 → 悬浮球，打开开关并允许「显示在其他应用上层」。开启后回到桌面，球在屏幕右边缘，可拖动；长时间不用会缩成半圆，点一下展开。

**Q4：磁贴怎么加到控制中心？**
下拉控制中心 → 点编辑（小米在右上角）→ 找到「辣脚记账 · 记一笔」→ 拖进快捷面板。

**Q5：累计结余为什么和首页「本月剩余」不一样？**
首页是「本月预算 − 本月已花」，只看当月；累计结余是每个月（预算 − 支出）的累加，看长期。两个数都對，只是口径不同。

**Q6：预算校准会改我的账单吗？**
不会，只改预算页显示的「已消费」数字，账单原样保留；可随时恢复自动统计。

**Q7：导入的账单分类不对？**
导入预览里可以逐条改分类；确认入账后也能在账单里点开修改。重复的交易会自动标记并跳过。

**Q8：换手机怎么迁移？**
旧手机：我的 → 数据备份 → 导出 JSON；新手机：安装后 → 我的 → 数据恢复 → 选择该文件。注意备份文件里是全部账单，请妥善保管。

**Q9：为什么安装包只有 157 KB？**
因为不塞广告 SDK、不塞统计 SDK、不联网请求；界面和图表都是本地代码，所以体积很小。

**Q10：以后还会加自动记账吗？**
会优先做「不读屏、不截屏、不驻留后台」的方案；在找到足够稳定的方式前，不会用一堆权限换一个时好时坏的功能。
